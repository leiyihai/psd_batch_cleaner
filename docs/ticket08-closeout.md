## CLI 与外部计划任务契约

`tests/test_serial_cli.py` 用独立解释器验证：部分清理非 0；失败优先于部分清理；任务异常优先于已发生的单文件失败；报告更新失败保留最近可靠记录；恢复后重跑；空范围总量明确为 0；中文/emoji 路径与帮助在 ASCII 父环境下仍正常。正常进程 import-time 审计不含 `pythoncom`、`win32com` 或 Photoshop 辅助模块。

stdout 最后一行的 JSON 字段：`state`、`exit_code`、`completed`、`total`、`counts`、`report`、`message`。任务异常为 error/2，总量或报告未知用 null；此前报告可能不含最后收到的全部结果，错误消息不能被忽略。参数解析错误仍按 argparse 返回 2，可能只有 usage/error；外围超时或强杀没有完整终态时一律不能视为成功。文本日志固定 UTF-8，旧测试调用方的 GBK 默认解码已显式改为 UTF-8，并验证读到终态，避免仅返回码为 0 却漏看 reader-thread 解码异常。
