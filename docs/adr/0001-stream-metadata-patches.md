# 使用文件区间补丁进行大文件深度清理

真实输入为 0.91–2.80 GB，递归 XMP 达 0.77–2.69 GB；全量 PSD 对象读写既放大内存，也会规范化未知数据和填充。批处理改用 psd-tools 的文件头、描述符及标签定义定位格式边界，只替换 XMP、必要长度及相关对齐字节，其余源区间分块原样复制，并逐区间比较输出；这取代批处理中的全量重序列化门禁，而非放宽未知数据保护。

保留旧的内存型原型用于既有回归；正常批处理不再受累计文件字节 2 GiB 的原型限制，改为单 XMP 128 MiB、累计替换数据 256 MiB、图层记录及解压合成图各 128 MiB、嵌套深度及文档数量的明确限制。已知 linked 后缀、常规 LayerInfo 及 Lr16/Lr32 必须读取校验，合成图检查 RAW/RLE/ZIP；无法验证的 Layr 替代存储拒绝发布。不能解释的 framing 越界或无法校验的修改仍拒绝发布，不自动转换格式或拼合；代价是需要维护严格的底层格式边界并固定库版本，且逐区间复制证明不能替代 Photoshop 的可编辑性验收。
