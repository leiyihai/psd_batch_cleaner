# 领域文档

本仓库采用 single-context 布局：
- 根目录 `GLOSSARY.md`：领域术语。
- `docs/adr/`：架构决策记录。

## 阅读规则

- 探索领域逻辑前，阅读 `GLOSSARY.md`。
- 修改相关设计前，阅读涉及该领域的 ADR。
- 文档不存在时正常继续，不为补齐目录而创建空文档。
- 如果以后存在 `GLOSSARY-MAP.md`，先读取映射，再读取当前任务相关上下文的术语表和 ADR。

## 使用规则

- 规格、工单、设计说明和测试名称沿用术语表的概念。
- 发现术语歧义时明确指出，不静默替换概念。
- 新方案与现有 ADR 冲突时，明确说明冲突及变更理由。
- 术语和决策确认后再记录，不将未确认方案写成既定事实。
