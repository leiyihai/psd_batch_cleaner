# Triage 状态

以下名称用于本地工单的 Status，不是 GitHub 标签。

| 角色 | 本地状态 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求明确，可由代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

ready-for-agent 不代表依赖已解除、任务已认领或已经完成。
是否可开始须同时检查 Blocked by；是否完成须检查验收及完成记录。
