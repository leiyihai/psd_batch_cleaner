# 05: 安全停止、单文件失败后继续与任务异常反馈

**What to build:** 用户可以在 GUI 中请求安全停止，当前文件完成或安全失败后不再启动下一项；坏文件不阻断其他文件，任务级故障、锁冲突和停止结果均清楚可见，并能安全开始后续任务。

**Blocked by:** 03 — 最小可用中文 GUI：选择目录并完成串行瘦身。

**Status:** ready-for-agent

- [ ] 提供停止操作和请求停止反馈，区分运行中、请求停止、已停止、已完成及任务异常；停止不显示成全部完成。
- [ ] 当前文件开始后不在解析或写入中间强行终止，完成或安全失败后停止启动下一文件；清理完成前界面不误报已停止。
- [ ] 单个损坏、解析失败或校验失败的文件记录原因且不发布半成品；未请求停止时继续处理后续文件。
- [ ] 报告或缓存无法可靠写入、输出基础设施失败等任务级异常明确终止并保留已有记录，不显示全量成功。
- [ ] 同一输出目录的任务互斥生效；锁冲突可读且不会覆盖其他任务的锁。异常遗留锁只提供确认无任务后处理的说明，不无条件强制解锁。
- [ ] 正常完成、停止及失败后正确释放任务资源并恢复 GUI 操作状态；不强制结束 Photoshop 或其他用户进程。
- [ ] 完成至少两文件的停止验收、坏文件后继续、写入及校验失败、任务锁冲突和异常后再次启动的回归；断言输出和报告，不只断言按钮文字。
