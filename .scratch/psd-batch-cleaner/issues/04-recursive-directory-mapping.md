# 04: GUI 递归扫描与子目录结果映射

**What to build:** 用户在 GUI 中通过默认勾选的“包含子文件夹”控制批处理范围，处理整个目录树并在输出位置按原目录结构找到每个瘦身副本；关闭该选项时只处理输入目录当前层级。

**Blocked by:** 03 — 最小可用中文 GUI：选择目录并完成串行瘦身。

**Status:** ready-for-agent

- [ ] GUI 提供默认开启、可关闭的包含子文件夹选项；GUI 与非交互入口共用同一递归参数和扫描行为。
- [ ] 识别 PSD/PSB 及大小写不同的扩展名，正确处理中文、空格和多级目录，不处理其他扩展名文件。
- [ ] 输出保留输入相对路径，不同子目录中的同名文件互不覆盖；历史输出仍遵循独立运行目录策略。
- [ ] 输入和输出目录相互包含时拒绝开始；扫描不跟随符号链接进入其他目录，不把输出重新作为输入。
- [ ] 扫描结束后显示可靠的文件总量及整体文件进度；最终结果数量与本轮选择范围一致，空目录有明确反馈。
- [ ] 无权限或扫描错误明确反馈，不静默显示为已完成全部扫描；不破坏原稿或已完成输出。
- [ ] 用包含嵌套目录、同名文件、混合扩展名、中文路径及空目录的隔离场景，端到端验收递归开启和关闭两种行为，并确认 GUI 选项实际控制任务范围。

## Comments

仅新增扫描范围与路径映射，不引入实时监听或内置计划任务。已运行任务的递归参数固定，不能由界面后续改动影响当前任务。
