# 02: 未知数据文档不中断批处理，禁止自动拼合

**What to build:** 用户批处理会触发 Photoshop“此文档包含未知数据”警告的真实文件时，能够安全保留内容则生成保留图层的瘦身副本；无法安全处理则不发布修改结果、记录兼容性原因并继续后续文件。整个正常清理过程不依赖弹窗确认，也不通过拼合或栅格化绕过问题。

**Blocked by:** None (can start immediately).

**Status:** needs-info

- [ ] 获取并识别可复现警告的真实样本，分别覆盖主文档及嵌入式智能对象；说明触发条件。仅有截图时记录材料缺口，不将其当作已复现或已修复。
- [ ] 明确“默认是”对应“保留图层”，不是“拼合”；同时承认 Photoshop 此选项可能丢弃未知数据，不能据此授权 Python 丢弃任意未知字段。
- [ ] 正常清理直接使用 psd-tools，不调用 Photoshop、不模拟点击弹窗；可以安全处理的样本完成清理后通过结构、图层可编辑性和视觉结果检查。
- [ ] 未知字段不能可靠保留、解析失败或未修改字节往返门禁失败时，原稿不变、不发布修改结果、报告明确兼容性错误；不把失败或未处理内容显示为完整成功。
- [ ] 使用包含问题文件和后续正常文件的隔离批次，验证不等待人工确认，且后续正常文件仍能完成。
- [ ] Photoshop 辅助验收遵循保留图层策略，实际核对图层和可编辑性；不能仅因关闭对话框显示就认定策略生效。辅助流程不能自动处理时明确失败或超时，不无限阻塞，不强制结束用户进程。
- [ ] 对已确认可安全保留的未知内容及保护性拒绝路径增加自动回归，并记录真实样本验收证据。真实警告样本未验收前，不以合成未知字段测试关闭本工单。

## Comments

本工单与 01 可并行，代码修正和共享样本需要协调。实际验收有外部材料前提：需要能触发截图警告的真实文件；未证明现有对比样本就是该文件。必要时在本地记录 needs-info，并保留所有未完成验收项。
