# 07: 逐文件结果、真实瘦身统计与报告导出

**What to build:** 用户可以在 GUI 中查看和导出逐文件清理结果、原始与结果大小、实际变化、输出位置、错误及未处理内容，并获得不夸大瘦身收益的分类汇总。

**Blocked by:** 03 — 最小可用中文 GUI：选择目录并完成串行瘦身。

**Status:** ready-for-agent

- [ ] 展示成功、无需清理、未变化、部分清理和失败五种文件状态及数量，状态含义与领域术语一致，不把删除数量等同于完整成功。
- [ ] 每项可查看来源、实际输出位置、已知的前后大小、字节及易读单位的实际差异、清理文档数量、跳过外链数量、未处理内容和错误原因。
- [ ] 部分清理逐项说明未处理内容；失败与无可用输出明确标注，未知大小不伪造为零或误算收益。
- [ ] 本轮收益只统计本轮实际发布且大小可核实的结果，明确部分清理的统计口径；历史复用、失败和未发布结果不重复计入，体积增加保留真实负收益。
- [ ] 界面可以查看长路径及完整错误，成功不逐文件弹窗；报告导出结果与同一批处理记录一致。
- [ ] 导出支持中文且不会默默覆盖既有用户文件；如使用表格格式，对用户可控文本处理公式注入风险。
- [ ] 用包含全部文件状态、体积减少、不变、增加及缺失大小的结果场景验收展示、分类统计和导出；保持 GUI 和导出共用同一结果数据，避免计算规则分叉。
- [ ] 本工单独立通过结果展示和导出回归；跨工单新增的停止及增量行为在最终整体验收中共同验证，不将 05 或 06 设为前置依赖。

## Comments

可基于已有批处理结果模型和稳定的结果场景独立实施，但需通过共享入口完成端到端验证，不能只做静态示例页面。导出格式尚未确认，选型不应改变已确认的数据及安全语义。
