# 01: 真实 PSD/PSB 深度清理与大文件验收

**What to build:** 用户能够通过现有非交互批处理入口，对代表性真实 PSD/PSB 生成独立瘦身副本，验证主文档和嵌入式 PSD/PSB 的祖先数据确实被清理、图层与智能对象仍可编辑，并获得可追溯的体积、耗时及峰值内存记录。复用已有原型，修正阻断约定样本验收的必要问题，不扩展为无限格式兼容性工程。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 建立代表性真实文件清单，覆盖 PSD、PSB、大文件、多层嵌入及多个图层实例共享同一嵌入内容；注明来源、大小、结构特征、测试环境与样本指纹，不自动上传用户文件。
- [x] 对有祖先数据的样本先证明字段存在，再验证主文档和受支持嵌入 PSD/PSB 中的目标字段已删除；其他元数据、共享标识和外链源文件保持不变。
- [ ] 检查输出能在 Photoshop 中打开、进入嵌入内容编辑、另存测试副本并重新打开；比较图层信息及实际渲染。验收仅使用隔离副本，不保存或关闭用户现有文档，不把能重新解析当作可编辑性验收。
- [x] 原稿及既有参考结果不被覆盖；无需清理时原样复制；不支持的非 PSD 嵌入内容明确报告部分清理。
- [x] 逐样本记录前后大小、实际变化、耗时、峰值内存及受限原因；如具备原 JSX 参考结果，说明差异，不能承诺两种路线瘦身量相同。
- [x] 遇到资源限制或严格往返门禁失败时，报告具体原因，不盲目放宽限制、不静默降级为主文档清理；修复后重跑约定样本及已有自动回归。
- [x] 自动测试以完整批处理输入、输出及报告为主要接缝，并补齐真实嵌套与共享实例的回归证据；合成容器不能替代原生智能对象验收。
- [ ] 明确记录每个约定样本通过、部分清理、拒绝发布或待验证的结果。关键真实文件仍有未解决阻塞时，本工单不得记为验收完成；截图未知数据问题由 02 单独验收。
